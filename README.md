# User Management System (Flask + MongoDB)

A complete User Management System built using ython Flask and MongoDB, featuring authentication, user CRUD operations, and a modern dark UI.

---

# Features

- User Registration & Login
- Session-based Authentication
- User Dashboard
- Add / Edit / Delete Users (CRUD)
- Secure Password Hashing
- Dark & Modern UI
- Clean Project Structure
- MongoDB Integration

---

# Tech Stack

- Backend: Python, Flask  
- Database: MongoDB  
- Frontend: HTML, CSS, JavaScript  
- Authentication: Session-based  
- Tools: Git, GitHub
